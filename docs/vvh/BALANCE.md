## Structural safeguards

The static validator checks that:

- currency is visible on quests rather than hidden inside choice tables;
- repeatables consume an unambiguous input and never return that input;
- reward counts stay within one stack per entry;
- building kits use flexible raw materials where specified;
- shared paid-entitlement scope, prices, and cooldowns are stated in descriptions;
- faction core spines remain [1, 2, 4] Bevel-equivalent;
- branch asymmetry is surfaced as a warning instead of being silently called
  equal.

Team completion and reward-claim behavior are separate FTB Quests runtime
behaviors. Verify one payment → one shared entitlement, payer/teammate claim
order, late joiners, full inventories, cooldown timing, and repeat resets in
the actual client; static totals remain source-level evidence only.
