This is the only permitted ID source for chapter authors. Every listed ID was read from an inspected JAR in `tmp/modcache`; existing quest text was not accepted as evidence. IDs not in this document are unverified for authoring.

## Verification scope

Inspected namespaces with campaign-scoped entries: cobblemon, cobblemonraiddens, create, exposure, icarus, irons_spellbooks, numismatics, supplementaries, vampiresdelight, vampiresneedumbrellas, vampirism. Namespace inclusion means its listed IDs have direct JAR evidence; it is not a claim that every registry entry in that namespace was exhaustively cataloged. The current Chapter 01–06 item and advancement references are the completeness boundary.

No requested namespace remains UNVERIFIED. Farmer's Delight is present in the inspected Prism inventory but intentionally has no catalog entries because cooking is out of campaign scope.

The copied/downloaded JAR cache is under `tmp/modcache/`. `tmp/` is not explicitly ignored, but all cache JARs are covered by the existing `*.jar` ignore rule; nothing from this task is staged.
