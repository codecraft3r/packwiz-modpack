# VvH Asset Sources

All VvH art is original generated pixel illustration stored in the Poiesis Living Atlas resource pack. The current release contains the season crest and Free Company writ, five chapter panoramas, and the ten Blood/Holy/mediator support assets from the Iron's Spells batch brief.

The quest files reference `poiesis:textures/questpics/vvh/` with forward-slash paths. Transparent outputs were chroma-key cleaned, despilled, resized with nearest-neighbor scaling, and checked for transparent corners. No external web artwork, hotlink, official logo, or third-party binary was added.
